Bone & Bamboo Tiles

Every tile in the game, drawn from code: the 108 suited tiles, honours, flowers and seasons, the back, and every enhancement, edition and chop. Switch colourways to compare the three art directions on the real pieces.

The set

34 kinds, 8 bonus tiles

A run starts with the three suits, 1 to 9, three of each (81 tiles). Winds, dragons, flowers and 4th copies are bought. The 1 of Bamboo is a tree sparrow, the game's guide.

At phone size

The wall, your hand, your table

Drawn at the sizes the game will use on a 360px phone. Each stack is fanned so the top strip of the two tiles beneath shows. That strip is where the corner index sits, so you can read what you'd dig to without taking anything.

Hand tiles are about 41px wide, wall tiles 40px, table tiles 26px. The raised tile in the hand is selected.

Modifiers

Enhancements

Applied by fortunes. They change the face, so you can tell them apart at a glance.

Editions and chops

Editions sit on the rim; chops are the red name stamps, Balatro's seals. Each chop carries a character for what it does.

Notes

  • One generator, tiles.js: BBTiles.svg({ suit, rank }, { theme, index, enh, edition, chop }). The same code renders the game, this page and the exported SVGs (129 files, every tile in every colourway).
  • Tiles are 60 × 80 units: a 56 × 72 face on a coloured back that shows 4 units below it, so a tile reads as a thick object.
  • Original drawings. Layouts follow the traditional counts but every motif is drawn here; no printed set is copied.
  • Characters need a CJK serif (Noto Serif SC, OFL). The game needs only these glyphs: 一二三四五六七八九 萬 東南西北 中發 梅蘭菊竹 春夏秋冬 再金書運.
