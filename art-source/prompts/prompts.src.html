Bone & Bamboo Art Prompts

Prompts for ChatGPT image generation, built the same way as Twelve Petals: one style block, a vibe, a format and a subject, pasted as one prompt. Round 1 is a style trial: three subjects in each of the three styles, so you can pick the look from real art. Round 2 is everything else, in the winning style.

How

Each image

  1. Start a fresh ChatGPT chat for every image, so styles don't bleed into each other.
  2. Tap Copy prompt and paste it whole. Don't edit it; if something comes out wrong, tell me and I'll change the block.
  3. If an image is close but off, ask ChatGPT for another take in the same chat. Keep the best.
  4. Save it under the file name shown, then attach it here in our chat. I'll review it against the checklist below and process the keepers.
Round 1

Style trial: 9 images

One spirit, one great beast and the first sheet of pictures for the dragons (the jokers: tiles whose face shows a picture). The guide is the Red Dragon tile itself, drawn in code, so it needs no image, each in all three styles. The tiles already exist in all three colourways in the tile kit, so you'll be able to see each style with its tiles.

Round 2

Everything else

Ready now, but best run after the trial picks a style. From the second image on in a style, attach the approved trial images as references (I'll add a reference block once we have them).

Style
Review

What I check

  • It reads at game size: 60px for spirits, 40px for dragon tiles, 18px for objects.
  • The background keys out: even #00FF00 green, a clean edge, no bright green in the figure.
  • It looks like the real craft, not a modern illustration of it.
  • One held item, the right one. No text, characters, seals or signatures.
  • All images in a style look like one hand made them.
  • Cultural care: hosts are respected figures, the Kitchen God above all. Nothing mocking.
