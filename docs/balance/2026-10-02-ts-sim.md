# Bone & Bamboo: the TypeScript simulator (M2, 2 October 2026)

`pnpm sim` plays the real engine (`src/engine`) headless with the ported bot and shoppers
(`src/engine/ai.ts`, `src/engine/shoppers.ts`). It reproduces the Python prototypes
(`tools/sim-py`, results in `2026-10-02-round.md` and `2026-10-02-run.md`) within noise.

```
pnpm sim round --n 2000
pnpm sim free  --runs 200
pnpm sim run   --runs 400 --shopper smart            # the design's teahouse
pnpm sim run   --runs 400 --shopper smart --python-shop   # the Python teahouse (no almanac pack)
```

is a free level-up for a casual shopper, worth about 7 points of casual win rate. The design's
numbers are the game's; `--python-shop` is the parity check.

## Differences from the Python simulators

- A single is only played with no set in hand and no discards (the design's rule); the bot
  discards first when it has discards left on its last play.
- Fortunes act on real tiles (the shopper chooses them with the Python rules).
- The shop has the Almanac pack, the Gold Leaf fortune, rerolls, selling and burn a kind (the
  shopper uses none of the last three).
